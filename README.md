## ⭐ Featured Projects

### Gmail MCP Assistant
Agentic email assistant built on the Model Context Protocol, with a 5-agent LangGraph pipeline (Planner → Triage → Researcher → Executor → Critic) reasoning over Gmail.

**Stack:** FastAPI, LangGraph, Anthropic Claude API, MCP SDK, ChromaDB, PostgreSQL, Redis, Google OAuth

**Key concepts:** Multi-agent orchestration, MCP tool calling, RAG, PII-aware agent critique

🔗 [Repository](https://github.com/RajChaudhary7706/GMAIL_MCP_ASSISTANT)

---

### MultiAgentX
A microservices platform for orchestrating specialized AI agents behind a unified API gateway, with Firebase-authenticated sessions cached in Redis.

**Stack:** React, Node.js, Express, MongoDB, Redis, Firebase Auth, Docker

**Key concepts:** API gateway pattern, reverse proxying, session caching, service decoupling

🔗 [Repository](https://github.com/RajChaudhary7706/MultiAgentX)

---

### AI Video & Meeting Assistant Agent
Transcribes and indexes video/audio content, then answers questions over it through a local RAG pipeline.

**Stack:** Python, LangChain, OpenAI Whisper, Sarvam AI, Mistral AI, ChromaDB, Streamlit

**Key concepts:** Speech-to-text pipelines, RAG over transcripts, structured extraction

🔗 [Repository](https://github.com/RajChaudhary7706/Video_Assistant_Agent)

---

### Visualization Agent
Analyzes any public Python repository, traces its execution and dependencies, and generates AI-written architecture diagrams and risk analysis.

**Stack:** FastAPI, React, OpenAI GPT-4o-mini, Mermaid.js, AST parsing

**Key concepts:** Static + runtime code analysis, dependency graphing, AI-generated documentation

🔗 [Repository](https://github.com/RajChaudhary7706/Visualization_Agent)

---

### Uber Clone Backend
A ride-booking backend with JWT-based authentication for riders and drivers, paired with an animated React frontend.

**Stack:** Node.js, Express, MongoDB, JWT, React, GSAP

**Key concepts:** Auth flows, token blacklisting, REST API design

🔗 [Repository](https://github.com/RajChaudhary7706/Uber77)

---

### ToolifyPro
A full-stack PDF and image utility suite — merge, compress, split, and convert — deployed as a decoupled frontend/backend service.

**Stack:** Node.js, Express, HTML/CSS/JS, Netlify, Render

**Key concepts:** File handling, CORS/Helmet security, decoupled deployment

🔗 [Repository](https://github.com/RajChaudhary7706/toolifypro)
